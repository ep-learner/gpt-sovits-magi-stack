# 03 - 使用文档

> 本仓库：`gpt-sovits-magi-stack` —— 用 GPT-SoVITS 克隆音色 + MAGI 阅读器听小说的本地方案。
> 原始教程见 [00-原始PRD.md](00-原始PRD.md)，技术方案见 [01-技术方案.md](01-技术方案.md)，架构见 [02-架构说明.md](02-架构说明.md)。00/01 为历史方案资料，路径与操作以本文为准。

---

## 一、机器与文件布局

### 硬件
- NVIDIA 显卡，**8 GB 显存**（本方案在 RTX 4060 Ti 8G 上验证）。
- 磁盘预留 30 GB 以上。
- 训练前关闭游戏、安卓模拟器、视频播放器等占用显存的程序。

### 当前目录约定

下表用 `<仓库父目录>` 表示依赖目录所在位置，默认与仓库同级；实际值由 `config\stack.yaml` 的 `dep_root` 决定，可在不入库的 `config\stack.local.yaml` 覆盖。

| 路径 | 内容 |
|---|---|
| `<仓库路径>\` | 本仓库：启动器、脚本、配置与文档 |
| `<仓库父目录>\aiVoiceDep\GPT-SoVITS-v2pro-20250604\` | GPT-SoVITS v2Pro 整合包、训练产物与模型权重 |
| `<仓库父目录>\aiVoiceDep\input\` | 训练素材，也可在文件选择框中选择其他位置的音频 |
| `<仓库父目录>\aiVoiceDep\magi\MAGI-portable-2.3.0.exe` | MAGI 阅读器便携版 |
| `<仓库父目录>\aiVoiceDep\huggingface\` | Hugging Face 缓存 |
| `<仓库父目录>\aiVoiceDep\modelscope\` | ModelScope 缓存 |
| `<仓库父目录>\aiVoiceDep\numba\` | numba JIT 缓存 |
| `%APPDATA%\magi\library.json` | MAGI 自身用户配置，启动器会同步其中的朗读设置 |

所有运行入口都会自动设置缓存环境变量，无需手动设置 `NUMBA_CACHE_DIR`。新电脑首次部署见 [initProject.md](../initProject.md)。

## 二、日常听书

1. 双击仓库中的 `launcher\启动器.bat`。
2. 点击 **启动或重启朗读服务**，等待状态区显示“朗读服务：运行中”。
3. 点击 **打开 MAGI 阅读器**，导入 TXT/EPUB 并点朗读。
4. 如需先检查声音，点击 **试听**，程序会生成并播放一小段音频。

状态区同时显示当前音色。日常使用不需要打开 PowerShell、编辑 YAML 或进入整合包目录。

> 听书时只开朗读服务，不要同时打开 WebUI 推理页，否则两个模型会争抢显存。MAGI 语速设为 1.1～1.2 通常更连贯。

## 三、训练新音色

### 1. 准备素材

建议使用 1～10 分钟单人、无背景音乐、无明显混响的干净人声，支持 wav、mp3、flac、m4a。首次 ASR 可能需要下载识别模型，保持网络可用。

### 2. 启动训练流程

1. 在「音色工坊」点击 **训练新音色**。
2. 选择音频，填写英文或拼音音色名，例如 `xiaoming`。名称已存在时需换一个，避免覆盖已有音色。
3. 等待自动切片和 ASR。完成后程序会用记事本打开 `output\asr_opt\<音色名>.list`。
4. 抽查并修正识别错字，尤其是数字、专有名词和书名；保存并关闭记事本。
5. 在弹窗中选择是否现在开始训练。

`.list` 每行格式为：

```text
<切片wav绝对路径>|<音色名>|ZH|<转录文本>
```

切片超过 15 秒建议删除；提示文本和实际发音必须逐字一致。若在校对弹窗中选择暂不训练，可之后通过高级命令继续，但已生成的素材不会自动变成可用音色。

### 3. 训练与启用

训练依次完成数据预处理、SoVITS 训练和 GPT 训练，使用 v2Pro 默认参数并关闭 DPO。状态栏会显示当前阶段，结束后弹出完成通知。

产出位置：

- SoVITS：`SoVITS_weights_v2Pro\<音色名>_*.pth`
- GPT：`GPT_weights_v2Pro\<音色名>-*.ckpt`

训练完成后选择“设为当前音色”，程序会自动切换并打开 MAGI；也可以稍后点击 **切换音色**。

> 8 GB 卡的 batch size 由程序按显存自动设置。若 OOM，先释放显存再重试，不要随意修改训练参数。

## 四、切换音色与试听

1. 点击 **切换音色**。
2. 从下拉框选择已训练音色，点击 **确定切换**。
3. 等待“切换完成”提示，在重新打开的 MAGI 中直接朗读，或先点击 **试听**。

切换会一次完成以下动作：

- 更新 `config\stack.yaml` 的 `current_voice`。
- 同步 API 端 `tts_infer.yaml` 的模型权重。
- 同步 MAGI 端 `library.json` 的参考音频、提示文本与服务地址。
- 服务正在运行时调用热切换端点，无需手动重启。
- 重新打开 MAGI，避免它用内存中的旧配置覆盖新设置。

当前音色的参考音频保存在整合包内，路径形如：

```text
<仓库父目录>\aiVoiceDep\GPT-SoVITS-v2pro-20250604\output\slicer_opt\<音色名>\<切片文件名>.wav
```

`config\stack.yaml` 中以相对路径记录，换电脑后仍可定位。参考音频应选 3～6 秒、单人、无背景音、语气平稳的片段，且提示文本必须与该片段逐字对应。

## 五、高级配置与命令行维护

日常训练、切换和试听都在启动器内完成。只有迁移目录、调整端口或人工指定参考音频时，才需要本节。

### 1. 公共默认与本机私有配置

`config\stack.yaml` 只保存可公开的公共默认：

| 配置段 | 用途 |
|---|---|
| `dep_root` | 依赖根目录，默认与仓库同级；换盘时优先改这一项 |
| `paths` | 整合包、MAGI、MAGI 配置和训练素材位置（相对 `dep_root`） |
| `cache` | Hugging Face、ModelScope、numba 缓存位置（相对 `dep_root`） |
| `server` | 朗读服务监听地址与端口 |
| `magi` | MAGI 调用 TTS 的协议版本 |
| `version` | 模型版本，本机为 v2Pro |

`current_voice`（实验名、参考音频、提示文本、语言）只写入**不入库**的 `config\stack.local.yaml`。启动器「切换音色」会自动维护这里，不要把它提交到 Git；仓库内的 `stack.yaml` 保持为空值。

点击启动器的 **编辑配置** 会打开 `config\stack.local.yaml`，保存并关闭记事本后自动应用；若服务或 MAGI 原先已打开，程序会重启它们。公共默认与私有配置同名字段以私有为准。可参照 `config\stack.local.yaml.example` 了解可覆盖项。

`config\_env.bat`、`config\_env.ps1`、`config\_env.py` 由程序生成，不要手改。`tts_infer.yaml` 与 `library.json` 的朗读配置也应由启动器或应用配置脚本维护。

### 2. 高级命令

在 PowerShell 中执行：

```powershell
$repo = "<本仓库路径>"

# 应用 stack.yaml，并同步 API 与 MAGI 配置
& "$repo\scripts\apply-config.ps1"

# 列出已训练音色
& "$repo\scripts\switch-voice.ps1" -List

# 切换音色；省略参考音频参数时会自动挑选切片
& "$repo\scripts\switch-voice.ps1" -Exp <音色名>

# 合成冒烟测试
& "$repo\scripts\test-tts.ps1"
```

直接启动服务可双击 `scripts\start-api.bat`。看到 `Uvicorn running on http://127.0.0.1:9880` 即成功，窗口需保持打开。

## 六、踩坑排查

| 现象 | 原因 | 处理 |
|---|---|---|
| `Failed to fetch` | 服务没启动或端口不一致 | 在启动器点击“启动或重启朗读服务”，确认状态为运行中 |
| `TTS 请求失败 (400)` | 参考音频不存在、超过 10 秒、提示文本不对应或语种错误 | 检查 `current_voice`，换 3～6 秒干净片段并逐字核对 |
| 声音不像 | 参考音频不合适，或提示文本与音频对不上 | 更换参考音频及对应提示文本；新人物差异较大时需要训练 |
| 切换后仍是旧声音 | MAGI 或服务仍持有旧配置 | 再执行一次“切换音色”；仍异常时重启朗读服务和 MAGI |
| 越听越卡 | WebUI 推理页也在占用显存 | 日常听书只开朗读服务 |
| 训练 OOM / `CUDA out of memory` | 显存被其他程序占用 | 关闭模拟器、游戏、视频软件，确认空闲显存后重试 |
| 合成胡言乱语 | 单次文本太长 | 按句合成；MAGI 会自动逐句请求 |
| `ModuleNotFoundError: No module named 'tools'` | 整合包 `runtime\Lib\site-packages\users.pth` 路径错误 | 确认其中路径均指向当前 `aiVoiceDep` 整合包根目录 |
| librosa/numba `cannot cache ... no locator available` | 未使用统一缓存环境 | 从启动器或仓库脚本启动，确认缓存指向 `aiVoiceDep\numba` |
| 首次 ASR 很久或失败 | 正在下载识别模型，或网络不可用 | 保持网络可用并查看状态；模型会进入 `aiVoiceDep\modelscope` |
