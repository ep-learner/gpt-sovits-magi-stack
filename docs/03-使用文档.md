## 二、从零开始的完整流程

### 0. 开工前（必做）
关闭占用显存的程序：**安卓模拟器（MuMu 等）、游戏、视频播放器（QQLive/爱奇艺）、多余的浏览器标签**。8 GB 卡训练时需要尽量空的显存，否则会 OOM。

### 1. 素材处理（切片 → ASR → 校对）
在整合包根目录执行（PowerShell，`D:\GPT-SoVITS-stack\GPT-SoVITS-v2pro-20250604`）：

```powershell
$v = "D:\GPT-SoVITS-stack\GPT-SoVITS-v2pro-20250604"
$env:NUMBA_CACHE_DIR = "C:\Users\admin\.cache\numba"
New-Item -ItemType Directory -Force -Path $env:NUMBA_CACHE_DIR | Out-Null
cd $v

# 1) 切片（参数为 WebUI 默认值；若超长片段过多，把 300 改成 100/200 重切）
& "$v\runtime\python.exe" -s tools/slice_audio.py "D:\GPT-SoVITS-stack\input\仙工开物.wav" "$v\output\slicer_opt\xiangong" "-34" "4000" "300" "10" "500" "0.9" "0.25" "0" "1"

# 2) ASR（首次会从 ModelScope 下载 FunASR 模型约 1 GB 到 tools/asr/models）
& "$v\runtime\python.exe" -s tools/asr/funasr_asr.py -i "$v\output\slicer_opt\xiangong" -o "$v\output\asr_opt" -l zh
```

产出 `output\asr_opt\xiangong.list`，每行格式：
```
<切片wav绝对路径>|xiangong|ZH|<转录文本>
```

**3) 校对**：打开 `.list`，至少抽查前 20 条，修正 ASR 错字（数字、专有名词、书名最易听错）。本仓库的训练集已把书名「仙工开物」的误识别修正。

> 切片时长要求：**删掉超过 15 秒的片段**，否则训练易出怪声。本次素材切出 23 条全部在 3~6 秒，无需删除。

### 2. 训练 v2Pro 模型
本仓库提供无头训练驱动 `scripts/train_v2pro.py`，复用 WebUI 完全相同的训练逻辑（参数全默认、关 DPO、v2Pro 全量微调），无需点 WebUI：

```powershell
$env:NUMBA_CACHE_DIR = "C:\Users\admin\.cache\numba"
& "D:\GPT-SoVITS-stack\GPT-SoVITS-v2pro-20250604\runtime\python.exe" `
    "C:\Users\admin\Documents\Trae-CN\default\gpt-sovits-magi-stack\scripts\train_v2pro.py" `
    --exp xiangong `
    --list "D:\GPT-SoVITS-stack\GPT-SoVITS-v2pro-20250604\output\asr_opt\xiangong.list" `
    --wav  "D:\GPT-SoVITS-stack\GPT-SoVITS-v2pro-20250604\output\slicer_opt\xiangong"
```

训练分三阶段（与 WebUI 一致）：
1. **1abc 数据预处理**：文本→音素/BERT、HuBERT 特征、说话人嵌入（v2Pro 需要 sv）、语义 token。
2. **1Ba SoVITS 训练**：默认 8 epoch。
3. **1Bb GPT 训练**：默认 15 epoch，**DPO 关闭**。

产出权重：
- SoVITS：`SoVITS_weights_v2Pro\xiangong_*.pth`
- GPT：`GPT_weights_v2Pro\xiangong*.ckpt`

> 8 GB 卡 batch_size 由程序按显存自动设为 4，**不要改参数**。若 OOM，先关闭占用显存的程序再重试，而不是调小 batch。

### 3. 让 API 加载训练好的权重
编辑 `GPT_SoVITS\configs\tts_infer.yaml` 的 **`custom:`** 段，指向刚训练出的权重（路径以实际文件名为准）：
```yaml
custom:
  bert_base_path: GPT_SoVITS/pretrained_models/chinese-roberta-wwm-ext-large
  cnhuhbert_base_path: GPT_SoVITS/pretrained_models/chinese-hubert-base
  device: cuda
  is_half: true
  t2s_weights_path: GPT_weights_v2Pro/xiangong.ckpt      # ← 你的 GPT 权重
  version: v2Pro
  vits_weights_path: SoVITS_weights_v2Pro/xiangong_8.pth  # ← 你的 SoVITS 权重
```
（也可在 API 启动后用 `/set_gpt_weights`、`/set_sovits_weights` 端点热切换，不重启。）

### 4. 启动 API 服务
双击仓库里的 `scripts\start-api.bat`（已含端口 9880 占用检查、`NUMBA_CACHE_DIR` 设置）。
看到这行即成功，**窗口别关**：
```
Uvicorn running on http://127.0.0.1:9880
```
> 关键：阅读器连的是 **API（端口 9880）**，不是 WebUI（9871~9874）。

### 5. 冒烟测试合成
PowerShell 执行仓库里的 `scripts\test-tts.ps1`，成功会在 `scripts\` 下生成 `test-output.wav`。播放确认音色像。

### 6. 配置 MAGI 阅读器
> **本机已预配置，开箱即用。** MAGI 的设置存在 `C:\Users\admin\AppData\Roaming\magi\library.json`，已预填好以下 4 项（MAGI 启动时会自动合并默认值，无需手动填）：

| 字段 | 已预填的值 |
|---|---|
| base_url | `http://127.0.0.1:9880` |
| 参考音频 | `D:\GPT-SoVITS-stack\GPT-SoVITS-v2pro-20250604\output\slicer_opt\xiangong\仙工开物.wav_0002204160_0002316800.wav` |
| 提示文本 | `山外则是群雄争霸，百舸争流。` |
| 语言 | `zh`（text_lang / prompt_lang） |

直接运行 `C:\Users\admin\.cache\magi\MAGI-portable-2.3.0.exe` → 导入书 → 点朗读即可。

**换音色时**（改了 API 端权重之后），需要在 MAGI 设置里同步更新参考音频和提示文本为新音色的片段，或直接编辑 `library.json` 的 `settings.tts` 段（字段名：`baseUrl` / `refAudioPath` / `promptText` / `textLang` / `promptLang` / `apiVersion`）。改之前先关 MAGI，否则退出时会被内存旧值覆盖。

参考音频挑选建议：单人、无背景音、语气平稳（别挑喊叫/耳语/哭腔），3~6 秒（超 10 秒直接报错）。完整字段说明见 `config\magi-config.example.txt`。

## 三、日常使用（跑通之后）

1. 双击 `start-api.bat` → 等 `Uvicorn running`。
2. 打开 MAGI → 导入 TXT/EPUB → 点朗读。
3. 语速设 1.1~1.2 可缓解句间停顿。

> 听书时**只开 API，别开 WebUI 推理页**，否则两个模型抢显存会越听越卡。

## 四、踩坑排查

| 现象 | 原因 | 处理 |
|---|---|---|
| `Failed to fetch` | 服务没起 / 地址填错 | 确认终端有 `Uvicorn running`；端口是 **9880** |
| `TTS 请求失败 (400)` | 参考音频路径不存在 / 带引号 / 超 10 秒 / 语种错 | 逐个排查，去掉路径引号 |
| 声音不像 | 参考音频不对，或提示文本与音频对不上 | 换 5 秒干净片段，逐字核对 |
| 越听越卡 | WebUI 推理页也开着抢显存 | 日常听书只开 API |
| 训练 OOM / `CUDA out of memory` | 显存被其它程序占用 | 关闭模拟器/游戏/视频播放器/多余浏览器，确认 `nvidia-smi` 有 ≥6 GB 空闲 |
| `Cannot find empty port` | Hyper-V/WSL 预留端口落在 9871~9880 | 改 `config.py` 端口（如 15001~15004），或释放预留端口 |
| 合成胡言乱语 | 单次文本太长 | 一次别超 50 字，按句切（MAGI 自动逐句请求） |
| `ModuleNotFoundError: No module named 'tools'` | 整合包 `runtime\Lib\site-packages\users.pth` 是打包者的旧路径 | 用 Python 重写该文件为当前整合包根路径（见技术方案） |
| librosa/numba `cannot cache ... no locator available` | numba 缓存放不进 D 盘 | 设置 `NUMBA_CACHE_DIR` 到 C 盘可写目录 |
