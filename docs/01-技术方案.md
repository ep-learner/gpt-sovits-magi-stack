# 技术方案

> 基于原始 PRD（`docs/00-原始PRD.md`），结合本机实际环境制定的完整执行方案。
> 目标：在本机独立完成模型训练，交付一个可双击启动、MAGI 可直接连接的本地 TTS 服务。
>
> **历史存档说明**：本文记录最初搭建时的路径与环境，其中的绝对路径已不代表当前布局。当前部署与跨设备初始化请以 [`initProject.md`](../initProject.md) 和 [`03-使用文档.md`](03-使用文档.md) 为准。

## 二、软件获取与部署

### 2.1 GPT-SoVITS 整合包

- **版本选择**：`GPT-SoVITS-v2pro-20250604.7z`（PRD 明确：8G 卡用 v2Pro；v3 只能 LoRA、v4 全量要 12G）。**不用** `-nvidia50` 变体（那是 RTX 50 系专用，我们是 4060Ti）。
- **下载源**：HuggingFace 仓库 `lj1995/GPT-SoVITS-windows-package`，走国内镜像 `hf-mirror.com`，用 `huggingface_hub` + `HF_XET_HIGH_PERFORMANCE=1` 多线程加速。
  - 直连 `huggingface.co` 在本机超时不可用；`hf-mirror.com` 单连接约 70KB/s 太慢，启用 Xet 高并发后可达数 MB/s。
  - 因 hf-xet 后端在 D 盘建临时目录会报权限错，**先下载到 C 盘默认缓存（`~/.cache/huggingface`），完成后复制到 D 盘**。
- **文件大小**：约 8.2 GB（`Content-Length: 8185086602`）。
- **解压**：7-Zip 解压到 `<仓库父目录>\aiVoiceDep\`，会生成同名子目录 `<仓库父目录>\aiVoiceDep\GPT-SoVITS-v2pro-20250604\`（运行时根目录）。
- **校验**：解压后确认存在 `runtime\python.exe`、`api_v2.py`、`go-webui.bat`、`GPT_SoVITS\pretrained_models\v2Pro\`（含 s2Gv2Pro.pth / s2Dv2Pro.pth）、`tools\uvr5`、`tools\asr`。

### 2.2 MAGI 阅读器

- **版本**：v2.3.0 portable（`MAGI-portable-2.3.0.exe`，144MB，免安装）。
- **来源**：https://github.com/noemoe5/MAGI/releases/latest
- **部署**：`<仓库父目录>\aiVoiceDep\magi\MAGI-portable-2.3.0.exe`（免安装便携版，双击即用；NSIS 自解压到 Temp 运行）。

### 2.3 目录布局（本机）

```
<仓库父目录>\aiVoiceDep\
├── downloads\                       ← 整合包 .7z 归档（解压后可删，当前仅余 HF 缓存探针）
├── GPT-SoVITS-v2pro-20250604\       ← 解压后的整合包（运行时根目录，~16 GB）
│   ├── output\slicer_opt\<实验名>\  ← 若干条切片（3~6 秒），其中一条兼作参考音频
│   ├── output\asr_opt\<实验名>.list ← 校对后的训练集标注（若干条）
│   ├── logs\<实验名>\               ← 1abc 预处理产出（HuBERT / sv / 语义 token）
│   ├── SoVITS_weights_v2Pro\<实验名>_e8_s184.pth   ← 训练产物 ★
│   └── GPT_weights_v2Pro\<实验名>-e15.ckpt         ← 训练产物 ★
└── input\                           ← 用户提供的训练素材（<素材文件>.wav）
<仓库父目录>\aiVoiceDep\magi\          ← MAGI 阅读器便携版（放 C 盘，不在 D 盘）
<仓库父目录>\aiVoiceDep\numba\         ← numba JIT 缓存（重定向到 C 盘，规避 D 盘写入）
```

## 三、素材处理（依赖用户提供素材）

> **唯一需要用户提供的输入**：1~5 分钟的目标音色干净人声音频（WAV/MP3）。放到 `<仓库父目录>\aiVoiceDep\input\`。

处理流水线（在 GPT-SoVITS WebUI 中完成，或命令行）：

```
input/raw.wav
  │
  ├─ 若有背景音乐/噪声 → UVR5 人声分离（tools/uvr5）→ 干净人声
  │
  ▼
音频切片（audio_slicer，阈值 300；若超长片段多则改 100~200）
  │
  ▼  按时长排序，删除 >15 秒的片段
切片目录（每段 1~15 秒）
  │
  ▼
ASR 转写（中文用 FunASR，tools/asr/funasr_asr.py）→ 生成 .list 标注
  格式: 音频路径|说话人|zh|文本
  │
  ▼
人工校对（至少抽查前 20 条；ASR 错字会原样进训练集）
  │
  ▼
最终训练集 .list
```

**参考音频挑选**（用于推理时锁定音色，独立于训练集）：
- 从素材中截一段 **3~6 秒**、单人、无背景音乐、无混响、**语气平稳**的片段；
- 用 ASR 得到其逐字文本（含半角标点），二者必须**一字不差**；
- 直接复用切片目录 `output\slicer_opt\<实验名>\` 中一条 3~6 秒片段即可（本次选用 `<参考切片>.wav`，其文本为 `<提示文本>`），无需单独拷贝到 `ref\`。

## 四、模型训练

- **版本**：v2Pro（8G 卡唯一可全量微调的版本；v3/v4 只能 LoRA、v5 跑不动）。
- **参数**：**全部默认**——整合包按显存自动调好（batch_size=4、is_half=True），不要手改。
- **DPO**：**关闭**（实验性功能，弊大于利）。
- **训练集**：第三步产出的 `output\asr_opt\<实验名>.list`（若干条，已校对）。
- **执行方式**：本仓库提供无头驱动 `scripts/train_v2pro.py`，复用 WebUI 完全相同的训练逻辑，无需点鼠标。因单条前台命令有 10 分钟上限，驱动支持 `--stage {all,1abc,1Ba,1Bb}` 分阶段跑（每阶段 <10 分钟）。
- **产物**（落在整合包根目录）：
  - 预处理：`logs\<实验名>\`（HuBERT 特征 / 说话人嵌入 / 语义 token）
  - SoVITS：`SoVITS_weights_v2Pro\<实验名>_e8_s184.pth`（8 epoch）
  - GPT：`GPT_weights_v2Pro\<实验名>-e15.ckpt`（15 epoch，DPO 关）
- **显存**：训练前关闭占用 GPU 的程序，确保空闲显存 ≥6GB。

> **Windows 沙箱坑**：本机会话中，**后台进程写 D 盘会被拒绝访问**（`PermissionError`），前台进程可写。因此训练一律以前台方式分阶段执行；所有 python 调用设置 `NUMBA_CACHE_DIR=<仓库父目录>\aiVoiceDep\numba`，规避 numba 缓存报错。详见 `docs/03-使用文档.md` 踩坑表。

## 五、推理 API 服务

### 5.1 启动

在整合包根目录 `<仓库父目录>\aiVoiceDep\GPT-SoVITS-v2pro-20250604\` 下：

```bat
runtime\python.exe api_v2.py -a 127.0.0.1 -p 9880 -c GPT_SoVITS/configs/tts_infer.yaml
```

看到 `Uvicorn running on http://127.0.0.1:9880` 即成功，窗口保持打开。

本仓库提供 `scripts\start-api.bat` 一键启动，内含：
- 端口 9880 占用检查（避免起两个实例打架）；
- 切换到整合包根目录；
- 用内置 `runtime\python.exe` 启动。

### 5.2 模型与参考音频绑定

`tts_infer.yaml`（或启动时通过参数）需指向：
- 训练产出的 SoVITS 模型（s2Gv2Pro 微调 ckpt）；
- 参考音频路径 + 参考文本 + 语言 `zh`。

> 音色由参考音频决定，模型提供"会说话的能力"。二者必须配套。

### 5.3 接口自测

`scripts\test-tts.ps1` 向 `http://127.0.0.1:9880/tts` 发一条测试文本，验证返回音频。这是服务就绪的准出标志。

## 六、MAGI 配置

在 MAGI 设置里填 4 个字段（与 `config/magi-config.example.txt` 一致）：

| 字段 | 值 |
|---|---|
| base_url | `http://127.0.0.1:9880` |
| 参考音频 | `<仓库父目录>\aiVoiceDep\GPT-SoVITS-v2pro-20250604\output\slicer_opt\<实验名>\<参考切片>.wav`（**不带引号**，3~6 秒） |
| 提示文本 | `<提示文本>`（与该音频 ASR 逐字一致，含标点） |
| 语言 | `zh` |

三个必避坑：
1. 参考音频路径**不带引号**（资源管理器"复制为路径"会带引号，会报 400）；
2. 提示文本与音频**逐字一致，标点也算**（全角/半角不一致会掉相似度）；
3. 参考音频与模型**配套**（换模型不换参考音频会出杂交音）。

## 七、端到端验证（准出）

1. `start-api.bat` 双击 → 终端出现 `Uvicorn running on http://127.0.0.1:9880`；
2. `test-tts.ps1` → 返回 200 + wav，播放确认是目标音色；
3. 打开 MAGI → 导入一本 TXT/EPUB → 点朗读 → 逐句高亮 + 目标音色播放；
4. 连续听 5 分钟，确认无明显卡顿、音色稳定。

全部通过 = 交付完成。日常使用：**双击 start-api.bat → 打开 MAGI → 点朗读**。

## 九、风险与回退

| 风险 | 应对 |
|---|---|
| hf-mirror 下载慢/断 | 启用 Xet 高并发；支持断点续传；C 盘缓存下完再搬 D 盘 |
| 训练时显存不足（OOM） | 关闭浏览器/豆包/视频/模拟器等占显存程序；确认选 v2Pro 而非 v3/v4 |
| 端口 9880 被 Hyper-V 预留占用（`Cannot find empty port`） | 改 `config.py` 端口到 15001 附近，同步改 start-api.bat 与 MAGI base_url |
| 合成胡言乱语 | 单次文本 ≤50 字，按句切；MAGI 本身逐句请求，天然规避 |
| 声音不像 | 检查参考音频（3~6s 干净平稳）与参考文本逐字一致；校对 ASR 训练集 |
| 素材有噪声 | 先用 UVR5 分离人声再切片 |
| 合规 | 仅供本人离线听书；克隆可识别真人声音需授权；公开发布需署名 GPT-SoVITS |
